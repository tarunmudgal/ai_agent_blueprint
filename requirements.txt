# ai_agent_blueprint — repo-wide runtime dependencies
#
# This file aggregates the runtime dependencies needed to run the examples
# across every chapter in this repo. Install with:
#
#     python3 -m pip install -r requirements.txt
#
# Each chapter also ships its own requirements.txt (e.g.
# 01-smart-intern-prompt-engineering/requirements.txt) with chapter-specific
# comments on *why* each package and version floor is needed — read that one
# if you only want to work through a single chapter. This root file exists
# so `pip install -r requirements.txt` works from the repo root too, and so
# it stays in sync as new chapters (Blueprints 2-5) are added.
# ---------------------------------------------------------------------------

# --- Chapter 1: The Smart Intern (Single-Shot Inquiries) -------------------

# Official Google Gen AI SDK. The >=1.55.0 floor is required for the
# Interactions API (client.interactions.create), used throughout Chapter 1.
google-genai>=1.55.0

# Loads GEMINI_API_KEY from a local .env file so the key never lives in
# shell history or source control.
python-dotenv>=1.0.0

# Structured output: model_json_schema() and model_validate_json() require
# Pydantic v2.
pydantic>=2.0.0

# --- Chapter 2: The Fixed Assembly Line (Sequential Pipelines) --------------
#
# No new packages. A pipeline is plain Python composing the same
# client.interactions.create calls Chapter 1 established -- the Stage/Pipeline
# classes, manifests, and validation gates are all built on the three
# packages above.

# --- Chapter 3: The Intelligent Library (Grounded Context) ------------------
#
# No new packages. google-genai already exposes client.models.embed_content for
# embeddings -- a different model (gemini-embedding-001), not a different
# library. Chunking, the in-memory index, and cosine similarity are plain
# Python; no vector-database package is required at this teaching scale.

# --- Chapter 4: The Autopilot Worker (The Tool-Using Loop) ------------------
#
# No new packages. Tool calling is a parameter (tools=[...]) on the same
# client.interactions.create call every prior chapter already uses -- not a
# new library. The manual inspect/execute/submit loop is plain Python.

# --- Chapter 5: The Connected Boardroom (Specialist Networks) --------------
#
# No new packages. A "specialist" is just another client.interactions.create
# call with its own system_instruction; a "Supervisor" is Chapter 4's
# tool-calling loop applied recursively, where each tool body dispatches to a
# specialist instead of touching data. This is the final chapter -- no
# further packages are ever added by this series.
